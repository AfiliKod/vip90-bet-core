Questions?
Answered.

The core platform — full frontend + backend source, admin panel, user & wallet management, bonus/VIP engine, referral system, crypto payments (USDT-TRC20), live chat, PWA support and 8-language i18n — is free and open source. The 13 in-house games, the live sports-betting odds feed, and the Palace casino aggregator connector are separately licensed add-ons, because each carries real ongoing operating/licensing cost on our side. See Pricing below for exact packaging.

Not for crypto-only operations. USDT-TRC20 payments don't require a gambling license. If you plan to accept fiat payments or operate in regulated markets, you'll need appropriate licensing. The platform is designed to be license-ready with KYC, AML, and responsible gambling tools built in.

Every game round uses HMAC-SHA256 cryptographic hashing. The server generates a secret seed before the round, and players can verify the outcome after. The algorithm is deterministic: same inputs always produce the same result. This means neither the operator nor the player can manipulate outcomes after the round starts.

Yes. Every game has configurable house edge, bet limits, and timing parameters — all adjustable from the admin panel. Crash: 5-30%, Mines: configurable payout factor, Roulette: European 2.7%, Blackjack: ~2%, and more. ~70 configurable fields across all 13 games.

Minimum: 4 vCPU, 8 GB RAM, 50 GB SSD. Node.js 20+ and MongoDB 6+ (or Docker). Recommended for production: 8 vCPU, 16 GB RAM, 100 GB SSD with a dedicated MongoDB instance. The platform includes health checks, structured logging, and graceful shutdown for production reliability.

HD wallet architecture using BIP44 derivation. Each user gets a unique deposit address. Deposits under $100 are auto-credited. Withdrawals under $15 auto-process from the hot wallet. All transactions are on-chain (TRON network) with zero commission — you only pay gas fees. Admin can set USDT/TRY conversion rate.
